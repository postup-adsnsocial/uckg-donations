Security and privacy

Layered protection to reduce the risk of data leaks.

Security does not depend on a single barrier. The platform combines credential, session, authorization, database and private-file protection while preserving the principle of least privilege.

Implemented

Protected passwords

Passwords are transformed with a derivation algorithm and individual salt; the original password is not stored in the database.

Implemented

Secure sessions

High-entropy opaque tokens, only the hash persisted, HTTP-only cookies, SameSite Strict and Secure in production.

Implemented

Church-level isolation

Church context applied to transactions, database policies and checks to prevent cross-church access.

Implemented

Role-based permissions

Routes and operations are enabled according to the user’s role and valid association with the active church.

Implemented

Private files

Images and PDFs remain in private storage. Access uses temporary links with a default five-minute validity.

Implemented

Limits and validation

Uploads restricted to JPEG or PNG up to 4 MB, origin policies, security headers and request-body limits.

Production readiness package
